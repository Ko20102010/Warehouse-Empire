# Artwork folder

Weapon Shop Empire v0.7.00 renders its original pixel-art map, buildings, terrain, people, workers, clients, monsters and interaction markers directly in `game.js`.

This folder is reserved for future modular pixel assets such as:

- `tiles/`
- `characters/`
- `buildings/`
- `items/`
- `effects/`

The previous soft-3D `shop_world.png` is intentionally removed from the playable package.

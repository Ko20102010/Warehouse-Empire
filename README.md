# Weapon Shop Empire

## Current Version: v0.6.00

A casual, phone-friendly fantasy weapon-shop game with soft-3D isometric artwork, tap movement, simple management, daily variety, three save slots, crafting, employees, retail customers, wholesale contracts, monsters and permanent progression.

## Upload to GitHub
Extract the ZIP and replace the repository root files with:

- `index.html`
- `style.css`
- `game.js`
- `shop_world.png`
- `README.md`

The bottom-left version marker must show **Weapon Shop Empire v0.6.00**.

## Camera and Phone Controls
- Default camera zoom is now 70%.
- Pinch with two fingers to zoom.
- Mouse wheel zooms on desktop.
- Use `−`, `＋`, and Overview buttons as alternatives.
- Double-click resets zoom to 70%.
- Zoom is remembered in each save slot.
- Tap anywhere on the map to move.

## Casual Guidance and Variety
- Five-step first-day tutorial, with Skip.
- `?` Suggested Action button identifies the best next task and moves the character or opens the correct page.
- Three rotating daily goals.
- One random daily event per day.
- Daily goals cover selling, crafting, tips and monsters.
- Completing all goals awards one Legacy Point.
- End-of-day financial/activity summary appears before the next day.
- Four product presets: Safe, Profit, Quality and Custom.
- Employee Apply All Recommendations assigns simple roles in one tap.
- Retail, Balanced and Wholesale crafting priority.

## Fun Improvements
- Personal crafting Hammer timing mini-game.
- Perfect timing raises quality chance but missing never destroys the item.
- Simple customer personalities: Impatient, Bargain, Experienced, Collector and Loyal.
- Customers visibly show their personality and request.
- Chance to discover the Slime Edge recipe when crafting a sword with Slime Gel.
- More explicit worker labels and blocked-status support.
